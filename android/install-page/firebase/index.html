Code Match テスター向けインストール手順

「You've been invited to test: Code Match」というメールが届いた方向けの手順です。メールはスマートフォンで開いてください。Google アカウント（Gmail のアドレス）でログインできる状態にしておきます。

ながれ
  1. 招待を受ける（メールから 3 回押す）
  2. 「App Tester」アプリを入れる（1 回だけ）
  3. App Tester から「Code Match」を入れる

途中で「有害なファイル」「不明なアプリ」「ブロックしました」などの警告が出ますが、これは Google Play 以外から入れるアプリに必ず出る表示です。この手順書に書いてあるボタンを押して進めてください。

A. 招待を受ける

A1メールの「元のメッセージを表示」を押す

Gmail でメールを開くと、途中までしか表示されません。下のほうにある 元のメッセージを表示 を押して、続きを出します。

A2「Get started」を押す

「How to start testing」の下にある青いボタン Get started を押します。

Google のログイン画面が出たら、このメールを受け取ったアドレスでログインしてください。

A3チェックを入れる

「Accept invitation as:」の下に自分の名前とアドレスが出ます。違うアカウントが出ているときは 切り替え で、メールを受け取ったアドレスに変えてください。

説明文の左にある □ を押してチェックを入れます。

A4「招待に応じる」を押す

チェックを入れると青くなる 招待に応じる を押します。これで招待は完了です。

B. 「App Tester」アプリを入れる

App Tester は、Code Match の新しいバージョンをお知らせしてくれるアプリです。最初に 1 回だけ入れます。

B1「App Tester をダウンロード」を押す

招待を受けると Code Match のページが開きます。画面の下にある App Tester をダウンロード を押します。

B2「ダウンロードを続行」を押す

「有害なファイルの可能性があります」と出たら、ダウンロードを続行 を押します（この画面は C の別の方法 に載せている画面と同じものです）。

B3ダウンロードしたファイルを開く

画面の上に「[開く] をクリックするか通知をスワイプして…」と出ます。画面の一番上から下に向かって指でなぞって通知を開き、app-tester.apk の通知を押します。

通知が見つからないときは、もう一度 App Tester をダウンロード を押します。「ファイルをもう一度ダウンロードしますか？」と出るので、青い文字の app-tester.apk を押します。

B4「設定」→ スイッチをオンにする

「権限が必要です」と出たら 設定 を押し、次の画面で この提供元のアプリを許可 のスイッチを押してオンにします。オンにすると自動で次の画面が出ます。

ここで「戻る」を押すと中断されます。そのまま待ってください。

B5「インストール」を押す

「このアプリをインストールしますか？ App Tester」と出たら インストール を押します。

B6「開く」を押す

「アプリをインストールしました」と出たら 開く を押します。App Tester が開きます。続きは C へ進んでください。

C. App Tester から「Code Match」を入れる

C1「Sign in with Google」を押す

App Tester を開くと青い画面が出ます。Sign in with Google を押します。

C2アカウントを選ぶ

「アカウントを選択」と出たら、招待メールを受け取ったアドレスを押します。一覧に無いときは 別のアカウントを追加 からログインします。

C3「Code Match」を押す

「テスト用アプリ」の一覧に出ている Code Match を押します。

C4チェックを入れて「このデバイスでテストを開始」を押す

説明文の左にある □ を押してチェックを入れ、青い このデバイスでテストを開始 を押します。この画面は初回だけ出ます。

C5「ダウンロード」を押す

Code Match のページが開きます。一番上のバージョン（例: 0.1.0 (1)）の下にある青い ダウンロード を押します。ダウンロードが終わると、インストールの画面が自動で出ます。

インストールが終わると、このボタンは C9 の画面のように「開く」に変わります。

C6「設定」→ スイッチをオンにする（初回だけ）

「権限が必要です」と出たら 設定 を押し、この提供元のアプリを許可 のスイッチをオンにします。B4 と同じ画面ですが、「Chrome」のところが「App Tester」になっています。

ここで「戻る」を押すと中断されます。そのまま待ってください。

C7「インストール」を押す

「このアプリをインストールしますか？ Code Match」と出たら インストール を押します。

C8「詳細」→「インストールする」を押す

「デバイスを保護するため、アプリをブロックしました」と出たら 詳細 を押し、文章が広がったら「OK」の少し上にある インストールする を押します。

「OK」を押すと中止されてしまいます。「OK」は押さないでください。

C9できあがり

「アプリをインストールしました」と出たら 開く を押します。App Tester に戻ったときは、Code Match のページの青い 開く でも起動できます。ホーム画面にも「Code Match」のアイコンが増えています。

初めて起動したときにカメラの使用を聞かれたら、アプリの使用時のみ を選んでください。

別の方法: App Tester を入れずにダウンロードする

App Tester がうまく入らないときは、招待を受けた直後のページからでも Code Match を入れられます。

1「ダウンロード」を押す

Code Match のページで、バージョンの下にある青い ダウンロード を押します。

2「ダウンロードを続行」を押す

「有害なファイルの可能性があります」と出たら ダウンロードを続行 を押します。

このあとは 通常のインストール手順ページ の手順 3 以降（「開く」→「設定」で許可 →「インストール」→「詳細」→「インストールする」）と同じです。

困ったときは

招待メールが見つからない
件名は「You've been invited to test: Code Match」、差出人は「Code Match (via Firebase App Distribution)」です。迷惑メールフォルダも確認してください。招待は 30 日で期限が切れます。切れてしまったら下の連絡先に再送を依頼してください。
「Get started」を押したら、別のアカウントの名前が出た
「切り替え」を押して、メールを受け取ったアドレスを選んでください。
「OK」を押してしまい、インストールされなかった
やり直せます。App Tester を開き、Code Match の「ダウンロード」からもう一度進めてください。
新しいバージョンが出たら
App Tester に通知とメールが届きます。App Tester で Code Match を開き、新しいバージョンの「ダウンロード」→「インストール」→「詳細」→「インストールする」の順に進めます（C5、C7、C8 と同じ）。C4 と C6 はもう出ません。今までの履歴は消えません。
