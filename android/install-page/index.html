Code Match のインストール

Android スマートフォンに「Code Match」を入れる手順です。下の青いボタンを押してから、この下の手順どおりに進めてください。ボタンは 1 回押せば十分です。

アプリをダウンロードCode Match（Android 用）

バージョン __VERSION__ ／ 更新日 __DATE__

途中で「有害」「不明なアプリ」「ブロック」などの警告が出ますが、これは Google Play 以外から入れるアプリに必ず出る表示です。

インストールの手順

1「アプリをダウンロード」を押す

上の青いボタンを押します。

2「ダウンロードを続行」を押す

「有害なファイルの可能性があります」と出たら、ダウンロードを続行 を押します。

3「開く」を押す

画面の上に「ダウンロードが完了しました」と出たら、右の 開く を押します。

表示が消えてしまったときは、画面右上の ⋮ を押し、ダウンロード を押して、一覧の CodeMatch.apk を押します。

もう一度「アプリをダウンロード」を押してしまったときは、「ファイルをもう一度ダウンロードしますか？」と出ます。そこに表示されている CodeMatch.apk を押すと、そのままインストールの画面（手順 4 または 6）に進めます。

名前が「CodeMatch (1).apk」のような入力欄になっていて押しても反応しないときは、ダウンロード を押してもう一度ダウンロードし、手順 3 の「開く」から進めてください。

4「設定」を押す

「権限が必要です」と出たら、設定 を押します。（2 回目以降のインストールでは出ません）

5「この提供元のアプリを許可」をオンにする

右側のスイッチ この提供元のアプリを許可 を押してオンにします。オンにすると、自動で次の画面が出ます。

ここで「戻る」を押すと中断されます。そのまま待ってください。

6「インストール」を押す

「このアプリをインストールしますか？」と出たら、インストール を押します。

7「詳細」→「インストールする」を押す

「デバイスを保護するため、アプリをブロックしました」と出たら、詳細 を押します。

「OK」を押すと中止されてしまいます。「OK」は押さないでください。

文章が広がったら、「OK」の少し上にある インストールする を押します。

8できあがり

「アプリをインストールしました」と出たら完了です。開く を押すとアプリが起動します。ホーム画面にも「Code Match」のアイコンが増えています。

初めて起動したときにカメラの使用を聞かれたら、アプリの使用時のみ を選んでください。

困ったときは

ダウンロードしただけで、何も起きない
手順 3 の「表示が消えてしまったときは」のとおり、Chrome の右上 ⋮ → ダウンロード → CodeMatch.apk を押してください。
もう一度「アプリをダウンロード」を押したら「ファイルをもう一度ダウンロードしますか？」と出た
表示されている「CodeMatch.apk」を押すと、ダウンロードし直さずにインストールの画面へ進めます。押しても反応しない場合は「ダウンロード」を押して、手順 3 の「開く」から進めてください。
「OK」を押してしまい、インストールされなかった
やり直せます。Chrome の右上 ⋮ → ダウンロード → CodeMatch.apk を押して、手順 6 から進めてください。
新しいバージョンに更新したい
このページからもう一度ダウンロードして、同じ手順で進めてください。手順 4〜5 は出ません。今までの履歴は消えません。
Chrome 以外のブラウザで開いている
画面の文言が少し違うことがありますが、流れは同じです。「開く」→「設定で許可」→「インストール」→「詳細」→「インストールする」の順に進めてください。
